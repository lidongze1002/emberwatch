# 案件表（CASES）

五个案子，一条规矩：**每一案的「规则」必须是一条能改变寻路、视野、门、时间或目标位置的机制**，不是加血、不是减伤、不是「Boss 有第二阶段」。

总则（五案共用）：

- 正交俯视，`CAM.scale = 1.4`，镜头跟随小队质心并钳制在案发区域边界内。见 `CAMERA.md`。
- 三人小队（老兵 / 新兵 / 提灯人）自己决定走位、打谁、何时退；玩家只下目标。
- 卷宗 HUD：案件号、地点、时码、三行目标（01/02/03）、右侧一条「本案规则」读数。没有血条雨、没有发光面板。
- 一案 2–4 分钟，全自动可跑通（`game.direct()`）。
- 每案只新增 **一个** 规则钩子（`game.rule.kind`），其余沿用：拉闸、集火、撤离、提灯、接管。

## 第一案 · 歌剧院 —— 土蜘蛛

- **地点与场景**：一层剧院。前厅（出生、电闸、出口）／观众席（座椅是可以穿视线的矮障碍）／舞台（台口、幕布、脚灯）。平面是「凹」字形，前厅与礼堂之间只有两条门洞。
- **怪谈出处**：土蜘蛛（日本，土中の蜘蛛；被当作被贬斥的土着神/怨灵）。这里取「她是从地板下被唱醒的」这一层，不取源平合战的典故。
- **一条规则**：**电闸没拉下时，礼堂一直在唱。** 在礼堂区域待满 3 秒，队员就改听「歌」的指令，自己走上台。拉闸要一个人在后台站 1.2 秒。
- **Boss 形象与打法**：白裙、红腰封、黑长发、裙下八条两段腿的土蜘蛛，从台口地板下站起。近身抓打（40 px / 12 伤害），血 46。死亡时裙下散出 3 只蜘蛛子（血 2、极快），必须清干净才算清场。打法：先拉闸让她「醒」，再把三个人拉到台口两侧形成交叉火力；蜘蛛子用提灯的闪光定住。
- **新增机制**：`rule.kind = 'power'` —— 区域持续伤害式的「魅惑」不是伤害，是**夺取控制权**（把队员变成会走路的任务失败条件）。同时它把「清场」和「目标」串起来：不拉闸，打完了也走不了。
- **亮相**：拉闸的那一刻，镜头离开小队，0.8 秒推到台口，给她一个剪影（压暗 42% + 台口反光），停 0.9 秒再交还跟随。见 `CAMERA.md` §7。这是全作唯一一次「镜头不跟着人」。
- **时长**：约 2 分钟（拉闸 12 秒，清场 30–50 秒，撤离 20 秒）。
- **参考**：Hotline Miami 的「一击致命 + 房间节奏」（借：进门即交火、死亡很快；不借：连杀计分、霓虹滤镜）。XCOM 的「规则化威胁」（借：威胁有明确触发条件，玩家可以读；不借：命中率百分比与掩体格子）。
- **教学点**：这是唯一一案「怪可以被子弹解决」，后面四案逐步把「打」这条出路拿走。

## 第二案 · 公寓走廊 —— 八尺様

- **地点与场景**：一栋回字形的老公寓，一层。外圈是走廊，中间是电梯井/住户块，中间有一条横向的近路（两扇防火门）把回字切成「8」字。八扇住户门沿着外圈排开，楼梯间在西南角。
- **怪谈出处**：八尺様（2ch 系都市传说；白色洋装、身高八尺、会「呼ぶ」）。取「应门 / 回头」两条禁忌，不取「被抓住就死」的绝对性。
- **一条规则**：**不要应门。** 每隔约 9 秒，有一扇门会响（先有 2 秒的敲门声提示）。提示结束后，340 px 内所有还能听话的队员会**自己**把当前目标改成那扇门——他们被「回应」吸引。走到门边 28 px 内的人会被门后的人抓走（倒地，可以被队友救起）。按空格（撤回）＝「别应门」，打断这次吸引，但进入 3 秒冷却。
- **她怎么拦路**：她速度只有 38 px/s，所以她不靠追。每隔 14 秒左右，只要**没有人正看着她**，她就会从下一扇门里出来，站到队伍前面的门口或走廊收窄处（中间那条横穿近路的两端），把回字走廊截成两段——你要么绕外圈，要么从她身边过。她**抓住一个人之后会退开**十秒：不是要打一场，是让你知道她来过，也把救人的时间留出来。
- **Boss 形象与打法**：八尺様不可杀。白裙、黑长发遮住整个头、赤脚，比人高出一截（半径 26，投影拉长）。子弹打中她只会让她**顿一下**（0.25 秒硬直、无伤害），这是拖延，不是输出。她把人按倒后会停下来「看」1.5 秒，这是救人的窗口。
- **她记得那扇门**：一旦有人应门被她抓走，她就记住那扇门；此后每隔一次敲门，她还去敲那一扇，并且直接站在门后。应过的那扇门会变成这一夜的固定陷阱，逼你改路线。
- **新增机制**：`rule.kind = 'knock'` —— 门与声音。它改的是**队员的目标与寻路**（自己走向门），以及玩家的操作节奏（只能用「别应门」打断）。这一案新增一条「天亮」时间线：撑到 75 秒，楼梯间的门开，所有还站着的人进去才算结案。
- **时长**：全自动 75 秒，中途至少一次真的险情（有人应门倒地，或被堵在过道里放倒）；人手 2.5–3 分钟。
- **参考**：Door Kickers 的「破门 / 门后未知」（借：门是信息与时间的单位；不借：暂停规划、路径点编辑）。Slender 的「注视即危险」（借：你看她的方式会改变她的行为；不借：镜头晃动、静态吓人 jump scare）。
- **不借**：不做「回头就秒杀」。被抓是可恢复的倒地，让自动指挥有得救。

## 第三案 · 不存在的车站 —— きさらぎ駅

- **地点与场景**：一个没有名字的乡下车站。北侧是轨道与停着的列车（实体，挡视线），中间是岛式站台，南、西、东三个出口各有一个门斗，门斗口是一道卷帘门。站台中央有柱子、长椅、小卖亭。
- **怪谈出处**：きさらぎ駅（2004 年 2ch 实况帖；不存在的站、没有时刻表、车会来但不该上）。取「时刻表决定哪扇门是真的」，不取「网上直播帖」的叙事框架。
- **一条规则**：**地图会变，而且没有票上不了车。** 每 16 秒换一次「这一班车」的出口：南 → 西 → 东 → 南……。只有当前出口的卷帘门是开的；另外两扇是实体墙。站台中间的小卖亭卖票：走到柜台前停 0.7 秒拿一张，一张票只放一个人过去。换班的瞬间，还留在门斗里的人会被卷帘门推回站台中央并擦伤 2 点。末班车 96 秒开走，没出去的人留下。
- **Boss**：没有 Boss。只有**关门**：卷帘门、站台灯、末班车。压力全部来自时刻表与路程。
- **新增机制**：`rule.kind = 'timetable'` —— 动态实体墙（卷帘门每 16 秒换一次开关）＋ 动态出口位置＋「一张票一个人」。它直接改**寻路**与**目标位置**：上一秒能走的路，下一秒是墙；想上车先得横穿站台去柜台。
- **时长**：约 2 分钟（6 个班次；最快 2.5 个班次能走完，慢则 4 个）。
- **参考**：Hotline Miami 的「按节拍推进」（借：一波一波的窗口期；不借：连杀奖励）。Backrooms 的「空间错了」（借：一间看起来很正常的房间，但出口不在你以为的地方；不借：无限随机迷宫）。
- **不借**：不做随机迷宫。这里的「变」是**可读的时刻表**，玩家能算，自动指挥也能算。

## 第四案 · 稻田 —— くねくね

- **地点与场景**：夜里的水田。六块水田（不可走，但**看得穿**），田埂是窄路，中央一条大田埂直通北边的农舍，横向两条小田埂可以换边；东侧还有**第二条田埂**把右边的田切成两半。田尾（南边最窄的那条沟）通到西南角的水口。两盏石灯：一盏在中段横埂的东头，一盏在水口的尽头。农舍在中央田埂的尽头，门口有一盏石灯。
- **怪谈出处**：くねくね（2ch 系；远处田里有个「弯来弯去」的东西，看得太清楚会疯）。取「不能细看」，不取「看了就自杀」的绝对结局。
- **一条规则**：**不能细看。** 每个队员有自己的「注视」条（0–1.8 秒）。当他的枪口方向（`aim`）落在某个くねくね的 ±0.5 rad 内、距离 240 px 内、且没有遮挡时，注视条累积；移开就衰减（2.6/秒）。满了，他就自己走进田里，被「看没了」（`taken`，不可救）。按 E ＝**移开目光**：全队看向一块**没有一只在枪口上**的空处 1.8 秒，冷却 1.6 秒。灯要在两盏石灯上各借一次火；火一点着，全队压着步子走（0.4×），因为火不能灭。
- **Boss 形象与打法**：田里八只「小」くねくね（细长、半透明白、像被风吹动的稻草人，只在被注视时动得越来越快），中央田埂尽头一只「大」くねくね（半径 40，注视累积速度 1.6×）。她**不可杀**，而且不停：慢慢朝队伍**要去的地方**挪（13→26 px/s），谁看得越久她越快（最高 88 px/s），到人跟前 110 px 才停。她不追人，她拦路——所以路线要算的是「什么时候可以从她面前过去」。打法只有一种：在田埂上持续移动，用「移开目光」卡着冷却过每一个点位，并且在两盏灯之间来回。
- **新增机制**：`rule.kind = 'gaze'` —— 视野/焦距。它改的是**谁能看哪里**：队员的自动瞄准（会看最近的威胁）在这里是负担，玩家必须主动把目光拿走。
- **胜负**：提灯人必须活着走进农舍（灯是任务）。提灯人被「看没」或倒地无人救 → 失败。其余两人是损耗品；灯进屋后其余人跟着进门，才算结案。
- **时长**：全自动 83 秒（两段田埂、两次借火、一路被大的那只拦着）；人手谨慎走 2–3 分钟。
- **参考**：Fatal Frame 的「取景框」（借：看＝一种有代价的动作；不借：拍照战斗、胶片数量）。Slender 的「注视累积」（借：注视时长是一个资源；不借：黑屏跳脸）。
- **不借**：不做「闭眼」按钮的纯 QTE。移开目光有冷却，所以路线必须提前算。

## 第五案 · 十三楼 —— 后室

- **地点与场景**：一层永远一样的办公楼。回字形走廊，中间是电梯井实体，外圈墙上十三扇没有把手的门，每扇门上一块搪瓷门牌，写着 1–13 中的一个数。地毯是湿的芥末黄，顶灯是日光灯管，会闪。楼梯间在西南角。
- **怪谈出处**：Backrooms（4chan / 网络共笔；黄色墙纸、湿地毯、日光灯、无穷房间）＋「十三楼」的楼层禁忌。取「楼层重复」，不取「实体图鉴」。
- **一条规则**：**楼层会重复。** 每层都要求你走进「门牌号等于本层数字」的那扇门；门牌号每层重排（1–13 的一个排列），而且**只有在 220 px 内才看得清牌子**。走对：整队被楼梯间「吐」回起点，层数 +1；走错：整队回到起点，层数归 1，并且这一层的「你」被留在走廊里。四层走完，楼梯间才是出口。
- **复制品**：从第二层起，每次换层都会在走廊里留下三个「复制品」：和你的队员同高、同轮廓，但外套是反的（内衬朝外）、没有灯、枪口是冷的。**一个守一扇门**：站在离门 74 px 的地方，不追远（超出自己那段 190 px 就回岗位），只在自家门口这一段开枪。没人可打的时候，它们**踩着队长的脚印走**——你刚才怎么绕过去的，它两三秒后照走一遍。血 32（是普通怪的两倍），可击杀，但每次换层都会重新出现。
- **抢门**：到第三层，守着你那扇「对的」门的那个会先动：它在离门 74 px 处往门里走。你不先把它按下去，它就先进去了——这一层作废，整队回到楼梯口，而它从上一层跟下来（一个没有岗位、只跟着脚印走的追兵）。只有第一次会这样；被它得手一次之后，这一夜它就只守不抢了。
- **换层＝重置**：楼梯把你们吐回去的时候，伤也一起重来（血量回满）；被它抢门抢掉一层时，倒下的人也会站起来——楼层是重复的，身上的洞不是新的。
- **打法**：不要在原地换弹式对射，边走边打，把换层当成脱战手段；守门的那一个要在他走进门之前按下去。
- **新增机制**：`rule.kind = 'floors'` —— 数门/标记。它改的是**目标位置与「世界状态」**：同一个房间，门牌每层重排；走错不是扣血，是回到起点。加上「近距离才读得清门牌」的视野限制，逼玩家真的走过去数门。
- **时长**：全自动 60–66 秒（含一次「回起点」）；人手 3 分钟。
- **参考**：Backrooms 的空间恐惧（借：重复、无窗、日光灯；不借：无限生成、实体图鉴）。Fatal Frame 的「近距离取景」（借：必须靠近才看得清；不借：相机战斗）。XCOM 的「镜像敌人」（借：敌人用你的规则；不借：数值成长）。
- **不借**：不做随机无限层。四层是写死的，门牌排列也是写死的——自动测试要能复现。

交付方式：

- `game/src/cases.js`：五份 `CASE` 数据（墙、水田、家具、门、区域、出生点、规则参数、Boss、报酬）。
- `game/src/rules.js`：每案的规则状态机、目标读数、以及 `directRules()`（队长的自动驾驶）。
- `game/src/level.js`：网格寻路 + **动态实体墙**（`setExtras`，车站卷帘门用它换地形）。
- `game/src/units.js`：同一套骨架；新增 `hachi`、`kune`、`mirror` 三种非人实体与敌方子弹。
- `game/src/roster.js`：局外的名册、现金、结算、招聘池、值班表与存档（`localStorage`）。
- 标题 → 卷宗目录 → 简报 → 游戏 → 结案 → 值班室（招聘／换班／存档）→ 选案；点地面即接管（`T` 交回队长）。
- `tools/nw-cases.mjs`：五案依次加载、直接驱动 `game.update` 到结案，断言每案 `won`，最后跑一条「五案 + 招人」的局外回归。

已知问题：

1. 第四案的全自动路线 89 秒（两段田埂、两盏石灯、一路被拦）；人手玩会慢到 2–3 分钟。想再拉长就得改地形，而不是再加灯。
2. 第二案：她的存在感来自「提前站到下一个门口」和「记住应过的那扇门」，而不是速度；如果玩家一路不回头、`别应门`也从不进冷却，她还是很难真正碰到人。这是有意的取舍（规则是门，不是追逐）。
3. 第三案拿到票之后仍然只有 41 秒左右：票让「横穿站台」有了理由，但没有真正拉长案子。要拉长就得改班次结构（例如第一班不停车），而不是再加一层流程。
4. 第一案的交火有随机弹道：自动跑偶尔会倒一个人再由队友救起（30 次连跑全部结案，32–40 s）。台口的「后退点落在墙里」已于轮 42 修掉——之前约 1/10 会出现三人挤在台口被逐个打倒。
5. 第五案：复制品会守门、会模仿、会抢门，血翻倍之后是一场真的交战；但它们仍然是「换层重生」的一次性压力，不是完整的 Boss 战。
6. 帧时：五案都在 16.7 ms（p95 17 上下；机器忙时 p95 会抖到 33，median 不变），1280×800@dsf1，Chrome；没有出现 pageerror。
