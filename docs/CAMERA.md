# 俯视投影规范（CAMERA）

夜巡科所有画面都是**正交俯视**：镜头垂直向下，90° 俯角，没有透视、没有灭点、没有缩短。
这份文件规定「从上往下看，一个东西应该长什么样」，以及每张图提交前怎么确认它没有跑偏。

---

## 1. 坐标与朝向

```
        屏幕上方 = 世界「北」 = 镜头看到的远处
                     ↑
        左 ← 屏幕 → 右
                     ↓
        屏幕下方 = 世界「南」 = 镜头脚下 / 靠近观众
```

- 人物、怪物、家具都只有**一个**朝向：局部坐标的 `-y` 是「正面/前方」，`+y` 是「背后」。
- 所有精灵（sprite）都在局部坐标里绘制，再整体旋转到 `aim`。**永远不要**为了「让玩家看清脸」而转回正面。
- 因此：屏幕上「向上走」的人，我们看到的是**头顶**，不是脸。

## 2. 光与影

- 主光固定来自**台口方向**（世界 `-y`，屏幕上方），色温偏暖；补光来自吊灯与出口。
- 因此所有物体：**上缘亮、下缘暗**，投影**向 `+y` 偏一点 `+x`** 落，软边、低对比。
- 物体「有高度」只靠三件事表达：投影偏移、上缘高光、接地处的暗部（AO）。**不靠画立面。**
- 手电的光锥从**枪口**发出，轴就是枪管的方向（`pose.js` 的 `muzzleOf()`）；不是从身体中心射出来的。枪口另有一颗 2–3 px 的亮斑。

## 3. 各类对象从上往下看到什么

| 对象 | 必须画 | 绝不能画 |
| --- | --- | --- |
| 人（站/走） | 头顶（头发或帽子）、肩线的宽度、前伸的手臂与手、枪的**顶面**、迈步时露出的膝/靴尖、脚下的软投影 | 脸、眼睛、胸口、腰带扣、鞋底、任何正面细节 |
| 电视头「办事员」 | 电视机**顶盖**（塑料外壳、倒角、散热槽、提手）、天线两根从后缘伸出、正面只有**一条被压扁的屏幕亮边**，以及屏幕光洒到前方地面的一小片 | 完整的屏幕、静态雪花图案、音量旋钮正面、任何「电视正面照」 |
| 座椅 | 靠背的顶面（一条厚边）、坐垫、椅脚的投影、绒布纹理 | 靠背立面、扶手侧面 |
| 幕布 | 布料的顶面褶皱（明暗条带）、金边、帷幕在地面上的投影 | 舞台口立面、演员的脸 |
| 门 / 出口 | 门槛与门扇的**顶边**、地面上的光 | 门板正面、把手正面 |
| 墙 | 墙体顶面、上缘高光、内侧墙脚的暗带 | 墙面砖缝立面、窗框正面 |

## 4. 提交前如何确认（逐条打勾）

1. **遮住屏幕测试**：把「屏幕/脸/正面」那块遮住，对象还认得出吗？认不出就是画成了侧视。
2. **旋转测试**：把这个精灵在脑子里转 90°。转完还是一个「从上往下看的同一件东西」吗？如果转完变成「侧躺的人」，说明画的是侧视。
3. **阴影测试**：投影是否统一朝 `+y`（下）偏 `+x`？方向不一致，就是每个物件各画各的。
4. **高光测试**：上缘是否比下缘亮？如果下缘更亮，光就来自镜头脚下，和台口主光矛盾。
5. **椭圆测试**：圆形物体（头、吊灯、盘子）在画面上必须是**圆**；被压成椭圆的，只允许是「有高度的圆柱体顶面」。
6. **A/B 对照**：把新精灵和旧精灵并排放在同一张图里，看它们是否像同一台摄影机拍的。
7. **1:1 与 1/4 缩略图都看**：缩略图里最先消失的细节，就是最不该画的那个细节。

## 5. 材质的基本功（和投影同等重要）

材质不是靠颜色，是靠**四层叠加**：

1. **底纹（pattern）**：木板有年轮与板缝，丝绒有细密的绒毛噪点，黄铜有细划痕，大理石有脉络。用离屏 canvas 生成一次，之后平铺。
2. **受光（gradient）**：每个面从亮到暗有一个方向正确的渐变；不允许纯色块。
3. **高光（specular）**：只在朝向主光的一侧给一条细亮边；金属要更硬更窄，布料更宽更软。
4. **接触暗部（AO）**：物体与地面、物体与物体相接处压暗一圈，宽度 4–8 px，透明度 0.25–0.45。

缺任何一层，物体就会像「贴纸」；四层齐了，同一套形状才会像「物件」。

## 6. 禁止清单

- 不允许出现「面向观众的脸/屏幕/门板」。
- 不允许为可读性放大某些部件的透视（例如把枪管画成梯形）。
- 不允许用纯黑阴影：阴影是带蓝的深色，且半透明。
- 不允许每个物件各用一套光向。
- 不允许用「描边」代替体积；体积靠高光与 AO。

## 7. 亮相镜头（`game.shot`）

普通游戏时间镜头只跟随小队质心；**只有在「有东西第一次站起来」的时候**，镜头才短暂离开队伍，给一个亮相，然后交还。

- 触发：第一案拉下电闸、土蜘蛛从台口起身（`game.shot = {kind:'rise', x, y, scale}`）。
- 节奏：**0.8 秒推到台口**（`push`）→ 0.9 秒停住（`hold`）→ 0.9 秒退回（`pull`），总 2.6 秒。推镜期间相机直接到位，不用跟随的指数平滑，否则 0.8 秒推不到。
- 取景：`scale = 1.92`，镜头中心放在她身前 100 px（`boss.y + 100`），人在画面上三分之一、脚在台口亮边之上，绝不切到画面外边。相机仍受楼层边界钳制。
- 剪影：起身的 0.9 秒里她由小到大、由暗到亮；推镜期间再压暗 42%，只留一圈台口反光——先是一个剪影，镜头交还时才是那个人。
- 画框：推镜权重 `w` 同时驱动上下各 54 px 的黑边（`0.92w` 不透明度），退镜时一起退掉。
- 交还：`shot.t > 2.6` 时 `game.shot = null`，镜头回到小队质心的平滑跟随，不再有第二次。

不允许把这个镜头用在普通遭遇、换层或死亡上：它是一次性的「她站起来了」，用多了就只是运镜。
