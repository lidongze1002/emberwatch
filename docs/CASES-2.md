# 第二批案子：十宗（轮 83）

第一批五宗（歌剧院、公寓走廊、不存在的车站、稻田、十三楼）各自有一种规矩。
这一批再添十宗，目标是：**每宗一条新规矩、一只新怪物、一张新楼层**，而不是把旧案子换个墙纸。
总数 15 宗，仍然一队三人、正上方俯视、无外部素材、中英两版。

实现上分两层：

- **六种可复用的交互原语**（`rules.js`）：`sequence` 按顺序去点位、`onebyone` 一次只许一人、
  `carry` 取物送到另一处、`face` 必须朝着某物后退、`freeze` 倒计时必须静止/躲藏、`dark` 明暗区轮换。
- **每宗自己的怪物**（`units.js` 行为 + `render.js` 画法）：轮廓、动作、弱点都不同。

## 每宗的验收

1. 能进、能打、能结案：`nw-cases` 里自动指挥 240 秒内 `won`，三人撤离（或规则允许的撤离数）。
2. 规矩能被违反，也能被规避：破坏条件会失败，按规矩走能赢。
3. 怪物至少有一个「只在它身上」的动作或弱点（写进 `CHARACTERS.md`）。
4. 中英词库键一致；英文页无中日韩字符。
5. 帧时 `nw-perf` ≤17.5 ms；无 pageerror。

## 不做

- 不引入 3D、不引入外部图片/音频。
- 不为新案子重写相机、光照、走位、武器系统（沿用 `pose/lighting/tactics`）。
- 不新增第二套经济：仍用现金、零件、废料、抚恤。
