# 立绘与头像：生成描述

给图像模型的现成提示词。**风格块**每条都带上，人物描述只换中间那段。
生成后按 `docs/META.md` 的尺寸交付：头像 256×256，立绘 768×1024。

---

## 风格块（中文版）

> 1970 年代香港/日本都市怪谈电影的美术：近黑的靛蓝与焦褐底色，单一暖光源（提灯或台口灯）从侧上方打来，冷调环境反光；细颗粒胶片质感，轻微暗角，低饱和，高对比；写实摄影感，不要霓虹、不要赛博朋克、不要卡通描边、不要发光 HUD。人物为半身/全身写实肖像，布料有厚度与磨损，皮肤有汗与灰。

## 风格块（English）

> 1970s Hong Kong / Japanese urban-legend cinema: near-black indigo and burnt umber ground, one warm key light (a lantern or a stage lamp) from above-left, cold ambient bounce, fine film grain, gentle vignette, desaturated, high contrast, photographic realism. No neon, no cyberpunk, no cartoon outlines, no glowing HUD. Realistic half/full-body portrait; cloth with weight and wear, skin with sweat and dust.

## 四、案件情报照片（黑白剧照，每案一张）

统一描述：**黑白、颗粒、倾斜构图、像从监控或旧报纸上裁下来的**，不出现人物正脸。

1. 歌剧院：空荡的池座与半开的红幕，台口有一盏没关的脚灯。
2. 公寓走廊：走廊尽头一扇开着的门，门里比走廊更黑。
3. 车站：无人站台，站牌上的字被水汽糊掉，时刻表只亮一格。
4. 稻田：夜里的田埂与一盏石灯，远处有一条竖着的白影。
5. 十三楼：同一条走廊，门牌全是同一个数字，地上有一圈粉笔画的门。

## 五、使用建议

- 头像：用**同一条风格块 + 半身描述**，裁成方图；生成时加 `shot on 35mm, f/2, grain`。
- 立绘：加 `full body, standing, three-quarter view, dark seamless background`，背景留纯黑便于抠图。
- 一次生成四张再挑；人物之间的差别靠**服装轮廓**，不要靠颜色（整体几乎无色）。

## 六、程序化立绘（轮 75）

美术没有外部图片，所以证件照在 `game/src/portraits.js` 里用 canvas 现画：`drawPortrait(ctx, x, y, size, person, number)`。
256×256 画一次、按 `轮廓|id|姓名号` 缓存，之后只 `drawImage` 缩放。

| 轮廓 `look` | 谁 | 靠什么认 |
| --- | --- | --- |
| `veteran` | 老兵 | 大檐帽 + 立起来的风衣领；左眉旧疤、灰白鬓角 |
| `rookie` | 新兵 | 雨衣兜帽（领口一道湿边）+ 额前三缕湿发 |
| `lamp` | 提灯人 | 低束黑发 + 粗呢高领；**主光从下往上**（下巴亮、额头暗） |
| `constable` | 老警（可招募） | 宽檐雨帽 + 哨绳 + 制服领 |
| `student` | 学生（可招募） | 乱发 + 圆眼镜（一片反光）+ 围巾 |
| `sister` | 修女（可招募） | 白头巾 + 黑纱 + 领口十字架 |
| `docker` | 码头工（可招募） | 油布帽 + 极宽的肩 + 盐霜下颌 |
| 空 | 临时工 / 没有档案 | 空相纸 + 铅笔编号，不崩、不画假脸 |

所有脸共用一套「稳定随机」参数：脸宽 27–32、脸长 35–40、眼距 0.31–0.38、眉高低、嘴宽、鼻宽、疤（老兵必有，其他人 1/4）、胡茬（老兵/码头工/老警）。
光：一盏暖主光（提灯人从下、其余从上左），一层冷环境反光，斜向暖光扫过整张照片，颗粒 + 暗角 + 相纸边。

出现的位置：值班室档案条（74×92）、招聘卡（92×116）、简报右侧三张（56×70）、选案页出勤三人（40×50）、局内左下卷宗卡（30×38）、结案点名（26×26）。
