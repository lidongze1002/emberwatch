# 提案（ROADMAP）

每一组功能先在这里写 5–8 行，再动代码。写完、测过，就在 `ITERATIONS.md` 记一行结果。

## 组 1 — 视距、呼吸、掉落与武器

- **要解决**：现在队员能看见整层楼，敌人隔着墙/半张地图也在画面上；没有声音告诉你“有人近了”；枪只有一种，子弹无限。
- **玩家多出什么选择**：走位会改变“能看见什么”；灯油变短会逼你回营地补；不同射程的枪决定接敌距离；弹药与换弹让“一直按住”不再是答案；地上的东西值得绕一步。
- **验收**：视距外敌人 `seen=false`；走到 16 px 内自动捡起并改变弹药/灯油；三种武器一次扳机的弹丸数分别为 1/5/1，信号枪带 3 秒燃烧；空仓换弹 0.9 秒内不出子弹。
- **不做**：不做迷雾贴图、不做音效资产、不做弹道下坠与穿墙。

## 组 3 — UI：一张摊在灯下的纸

- **要解决**：HUD 还是「居中、等距、发光描边」的游戏语法；目标是一条会变绿的待办条；世界里的血条是一条街机长条。
- **玩家多出什么**：读起来像卷宗：打钩清单、铅笔划掉的项、盖歪的红章、带订书钉的相纸；受伤只在两秒内写一个小数字。
- **验收**：目标完成是方框 + 勾 + 斜线；印章 −3°～−5° 且有缺墨；照片有相纸边/订书钉/编号+日期；1:1 与 1/4 两张截图都能读；`nw-cases` 5/5、`nw-perf` ≤17.5。
- **不做**：不重排整个标题页，不改世界打光，不做动画过渡。


## 组 2 — 营地与武器升级

- **要解决**：案与案之间只有一张值班室表格，没有“回到办公室”的地方；枪永远一样，钱只能招人/买灯。
- **玩家多出什么选择**：地图板/名册/工作台/储物柜/电台/行军床/账本七件事各是一张纸；零件 + 现金决定先升哪把枪的哪个槽；电台的钱可以换人或者买下一案情报；行军床让伤员跳过一夜。
- **验收**：工作台买“步枪 枪管 I”扣 400 + 2 零件；下一案老兵射程 300 → 324；刷新后 `arms.rifle.barrel=1`；行军床把 `wounds` 清零；电台刷新扣 300 并换一批候选人。
- **不做**：不做二级材料合成、不做武器涂装、不做营地人物走动。
