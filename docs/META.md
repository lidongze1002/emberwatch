# 局外机制（META）

五案之间的那一层：钱、人、档案、下一案。原则是**局外不做数值膨胀**，只做「换人、换装备、承担后果」。

---

## 1. 循环

```
结案 → 结算（报酬 / 伤员 / 阵亡） → 招人 / 换装备 → 选案 → 简报 → 对局
```

- 每案结束进**结算页**：案子报酬、伤员医疗费、阵亡抚恤、剩余现金；然后进**值班室**（roster）。
- 选案页只显示已解锁的案子；失败可以重打，但伤亡与花费不退。

## 2. 钱

| 项目 | 数额（示例，先跑通再调） |
| --- | --- |
| 第一案报酬 | ¥ 1,200 |
| 第二案 | ¥ 1,800 |
| 第三案 | ¥ 2,400 |
| 第四案 | ¥ 3,000 |
| 第五案 | ¥ 3,600 |
| 轻伤（倒地但救回） | −¥ 300 / 人 |
| 阵亡 | −¥ 800 抚恤，且该员永久消失 |
| 招募一名新人 | ¥ 600 – ¥ 1,400（按资质） |
| 装备：好一点的灯 | ¥ 900（光锥 +8%，灯油消耗 −10%） |

现金为负不解雇，只是**下一案只能带两个人**（第三案起才有第三人位）。

## 3. 人

- 每案上阵 **3 人**；值班室里最多存 **6 人**，多的人要付 ¥ 200/案 的待命费。
- 每人有：**角色**（老兵/新兵/提灯人/…）、**一个特质**（改一条规则）、**两个数字**（伤势、参与案数）。
- 特质示例：
  - 夜眼：手电射程 +15%
  - 怕黑：灯一灭就自己后退（不听指令）
  - 老练：倒地后自救时间减半
  - 耳背：不会被敲门吸引（第二案直接克制）
  - 手稳：抵肩姿态后坐更小、连射更准
- 参与满 3 案的人获得第二个特质；阵亡即清空档案（在案卷里留一行黑框）。

## 4. 招募

- 每次结案后刷新 **2–3 名候选人**，带照片、角色、特质、要价。
- 招募是**一次性的**：不招就走，下案换一批。
- 候选人可以重复角色，特质不重复（同一特质全院最多一人）。

## 5. 档案与立绘

- **头像**（256×256）：卷宗里的一寸照，黑白偏棕，带颗粒与纸边。
- **立绘**（768×1024，透明或深底）：值班室与简报页用的半身/全身像，冷光 + 一盏暖灯。
- 每案简报左侧放**本案情报照片**（场景黑白剧照），右侧放三名上阵者的头像。
- 结案页用**红章**盖在照片上（`CASE CLOSED` / `NO ONE CAME BACK`）。

## 6. 界面

三张纸，全部沿用卷宗语言（细线、打字机体、红章）：

1. **值班室**：六个人的档案条（照片、名字、角色、特质、伤势、参与案数），底部现金与「招聘」「选案」。
2. **招聘**：两到三张候选人卡（照片、要价、特质），一个「不招」。
3. **选案**：五案列表（案号、地点、规则一行、状态：未解 / 已结 / 重打），右侧是上阵三人。

## 7. 实现顺序（给执行会话）

1. `game/src/roster.js`：现金、成员、特质、结算、招聘池（纯数据，无绘制）。
2. `game/src/overlays.js` 增三页：值班室 / 招聘 / 选案。
3. `game/src/render.js` 只加「头像框」与「情报照片」的绘制（照片先用程序生成的模糊场景缩略图占位，立绘位留空，等美术）。
4. `game/src/cases/*`：每案带 `fee`、`photo` 字段。
5. 用 `tools/nw-cases.mjs` 扩一条「连打五案 + 招人」的回归。

> 美术未到位之前，立绘位用**空白相纸 + 一行铅笔编号**（`NO PHOTO ON FILE`），这比错误的占位图更符合卷宗气质。
