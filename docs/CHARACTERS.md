## 2. 朝向与步态

- **身体朝向 `facing`**：由速度方向决定，转向角速度上限 7 rad/s，入弯会「压弯」。
- **上身朝向 `aim`**：由目标决定；渲染时上半身绕躯干再转 `aim − facing`，所以「人朝走的方向、枪朝目标」。
- 速度不是瞬时的：加速度收敛约 8/s，到点削速 0.5，撞墙只清被挡轴。
- 步幅与**实际速度**成正比（0→7.4 px 摆幅），慢走腿不动，快走才迈开。
- **布片**：下摆滞后于位移（弹簧约 7/s），转身会甩；下摆画在腿之前、躯干之后。

## 3. 两种架枪

| 姿态 | 触发 | 画法 |
| --- | --- | --- |
| 抵肩（ready） | 交火 / 有目标 | 枪贴身体，双手前伸，开火后坐 3 px 再回 |
| 斜持（carry） | 移动 / 驻守 / 移开目光 | 枪横过身体 +0.42 rad，枪口下压，靠近髋部 |

两种姿态之间**不是瞬切**：`poseT` 在 0.15 秒内线性走过去（6.7/秒），换姿势时枪与双手一起下沉 1.7 px、再回位（`poseDip` 由姿态变化速度驱动，9/秒衰减）。所以「抬枪」是一下抬起来的过程，不是贴图换了一张。

### 3b. 瞄准状态机（轮 71）

枪口不再被直接赋成目标角度，而是走一套有限的转动：

| 阶段 | 条件 | 行为 |
| --- | --- | --- |
| 发现 | 目标进入视野 | `acquire` 计时 0.22 s：**停步**（16/s 刹车），上身按 ≤7 rad/s 转向 |
| 对准 | 误差 ≤8° 且 acquire 满 | 才允许开火；子弹沿 `aim` 出膛 |
| 收枪 | 目标消失 0.25 s 后 | `aim` 以 7 rad/s 回到 `facing`，`poseT` 回到 carry |
| 扫射 | 移动中目标在 ±1.2 rad 内 | 保持走动，枪口以 7 rad/s 扫过去，扫到 8° 内才打 |
| 转身 | 目标超出 ±1.2 rad | 腰拧到头，脚停下，`facing` 以 3.6 rad/s 转向；`aim` 始终钳在 `facing ±1.2` |

- 腰拧上限 `TWIST_MAX = 1.2` 是每帧最后一步的硬钳制，渲染里的 `twist` 用同一上限；「甩头 90° 打一枪再甩回来」因此不可能发生。
- 开火的一瞬 `firePulse = 1`（7/s 衰减）：两脚各分开 0.8 px、整个人下沉 0.7 px；扫射时枪口有一条随 `aimSweep` 拉长的横向残影（1–2 帧）。
- 亲手接管（`possessed`）与「移开目光」（`aversion`）不受腰拧钳制：前者是光标指哪打哪，后者是真的把头转开。

### 3c. 枪、光、子弹同向（轮 76）

`game/src/pose.js` 的 `poseOf(a)` 与 `muzzleOf(a)` 是唯一一份姿态数学：渲染画枪、手电打光、子弹出膛三处都读它。

- 局部枪口 `(3.2, −26)`，依次经过 `twist → lean → 下沉 → 横移 → step → facing+90°`，得到世界坐标。
- 枪管朝向 = `facing + stepRot + leanRot + twist + carry`。
- 斜持时 `carry = −0.42`（约 24°），光锥和子弹都跟着低下去；光锥射程同时压到 62%（近距离的枪灯）。
- `aim` 仍走第 3b 节的状态机（acquire、7 rad/s、±1.2 腰拧）；枪和光只是它的机械结果。
- 光锥根部有一颗 2–3 px 的暖白亮斑，位置就是枪口。


## 4. 光

- 主光在台口 `(840,180)`，所以**上缘亮、下缘暗**，投影统一 `+x/+y`。
- 每个角色自己算「光相对自己朝向」的角度，把**轮廓光**放在真正朝光的一侧。
- 接触阴影：每人脚下一块软椭圆，随身体移动，不随旋转。

## 4b. 队形与战术动作（轮 72）

`game/src/tactics.js` 只管站位与朝向，不改胜负条件。

| 习惯 | 落法 |
| --- | --- |
| 角色 | 按名册顺序 point / cover / rear；有人倒下时角色顺延（3 号自动补位） |
| 分区 | 驻守朝向 = 队伍行进方向 + 0 / +2.0 / −2.0 rad；两两至少 115°，没有人看同一个扇区 |
| 门口堆叠 | 停在门口 118 px 内的人进入 stack：枪口下压（carry），第 2/3 位一只手搭在前面那人的肩上（局部坐标 (−1.9,−7.4) 的皮手套） |
| 交替跃进 | 有接触（活着的敌人距任一队员 <340 px）时，每 **4 秒** 换一个人停步警戒；同一时刻最多 2 人在动。停下的位置在 `boundTarget` 里，离队 >150 px 或血量 <40% 立刻自己跟上 |
| 不在门框停 | 站在门中心 26 px 内的人被挪到门面外 42 px；只有「进门读门牌」的 goto 不受影响 |
| 警戒 | 停步的人画一片 0.1 透明度的琥珀扇区（±0.32 rad，46 px），**在开火/集火时不画** |
| 记录 | 每次换警戒的人写一条 `bound` 日志（左栏能看见「谁留下警戒」） |

`sectorFor(index, heading)`、`stackSlots(x, y, nx, ny)`、`dominationPoint(zone, index)` 都是纯函数，可以被测试脚本直接调用。

## 4c. 走位：三个人不互相挡（轮 82）

规则只有一条：**想让开的人提前走位，不让路的人站住不动，谁都不瞬移。**

| 情况 | 做法 | 代码 |
| --- | --- | --- |
| 前面有人 | 往空的一侧侧身（±0.5–0.95 rad），并按距离减速 | `makeWay()` |
| 同向跟车 | 只对「正前方、比自己慢」的人减速，最低留 **45%** 速度：排队可以，停死不行 | `makeWay()` |
| 正前方被站定的人堵住 | 站定的人每帧让 **0.8 px**，一次最多 30 px；有敌人在 300 px 内时不让 | `yieldStep()` |
| 真叠上了 | 只处理 **18 px** 以内：一帧最多推 1.2 px；推不进墙就顺着墙滑；走的人让得多，站定的人不被拖走 | `updateUnits()` 的 `slide()` |
| 路点被人占 | 不丢路点、不瞬移；占满 1.1 秒才重算一条路 | `walkTo()` |
| 卡在墙角 | 0.9 秒没挪出 8 px 才判定；连续卡三次，才允许一次 **10 px** 的错步（原来最多 28 px 的瞬移已删除） | `walkTo()` |
| 被挤进墙里（敌人） | 每 0.5 秒往最近空地挪 **12 px**，不再整段瞬移 | `updateUnits()` |

两个人对开时按各自的 `lane`（提灯人 −1、其余 +1）错开，实测最近 18–20 px，8 秒内各到对面。
验收在 `tools/nw-walk.mjs`：五案实跑无重叠（<10 px 为 0 帧）、无瞬移（十三楼换层除外）、同一扇门 3/3 在 10 秒内通过。

## 5. 电视头「办事员」

- 顶部是**电视机顶盖**（不是正面）：30×24 的倒角塑料壳、后缘三道散热槽、提手、两根后伸天线。
- 屏幕只能看到**前缘一条亮缝**，加上向前洒到地面的一片青光（这也是它「看」的方向）。
- 身体：米色西装、翻领、白衬衫、领带、两颗扣子、垂着的手；西装下摆同样有布片滞后。
- 攻击：近身抓打（26 px），伤害 5，冷却 1.15 s；血 6；被击中冒暗红点。
- **死亡**：先向前栽倒（0.55 s，身体顺着枪口方向扑出去、电视压在更前面），落地之后才留残渣（那块碎掉的电视）。残渣是地面上的东西，不再挡人。

## 6. 土蜘蛛（第一案 Boss）

- 出现在**台口**：拉闸之后才站起来（电一断，她就醒）。
- 白裙、红腰封、黑发，**八条细腿**从裙下伸出并在走动时轻微摆动；头只画颅顶。
- 数值：血 46、速度 20、近身 40 px / 伤害 12 / 冷却 1.3 s。
- 死亡时从裙下**散出 3 只蜘蛛子**（血 2、速度 70、伤害 4），必须一并清掉才算结案。
- **死亡动作**：先跪落 0.45 s（裙子塌下去、头往下沉、八条腿收进来、脚下压出一圈更深的影），然后才散出蜘蛛子；这半秒里她不再攻击，也不再算「已清场」。
- 视觉：比办事员大一圈（半径 26），脚下投影更大；受击时裙面出现裂纹。
- **轮廓（轮 23 之后）**：裙子一端收尖＝蛾；所以肩线是一条钝边（±12 → 下摆 ±21 的喇叭），交叠的领口两道深线 + 一道浅里衬，两只和服袖从肩上垂下。黑发是一条从头顶到尾骨的窄尾，不是肚子上的黑斑。头只有颅顶 + 一圈随光转的缘光——她背后的台口是黑的，不补就只剩一个洞。
- **八条腿**：先算点集再画三层——脚下小暗结、大腿 3.2 px／小腿 1.9 px、每段朝光侧 0.7 px 暖缘光；膝关节 2.1 px 硬珠 + 一点高光。缘光方向由 `KEY` 相对她的朝向量出，转身时亮面跟着转。
- **登场地点**：`spawns.stageMark` 上有一块 104×68 的暗门（板缝、两只合页、缝里的暖光、台侧两条麻绳），她从那块板下面升上来。

## 6b. 八尺様（第二案 Boss）

- 白裙、黑长发、赤脚；她是「比人高」，但俯视看不到个子，所以大的是**裙摆、投影与半径**，不是头。
- **轮廓（轮 28 之后）**：钝肩线 ±15、圆肩角、下摆 ±23；高领是两道压在一起的领边；头发收窄并带一条 0.8 px 黑边与一根 20% 的发丝光；手臂垂在身侧、比裙子暗一档（原先同色，等于没有手臂）。
- **不要画脚**：长裙从上看不见脚，而两只白脚正好落在脸的位置，会读成眼睛。
- 她记住的门在走廊一侧有一个**红粉笔叉**（1.6 px，透明度 0.55），位置用 `doorStand()` 同一套朝向。
