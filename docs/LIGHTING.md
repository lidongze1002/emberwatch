# 光与遮挡（LIGHTING）

这一层决定「看得见什么」，不决定「能不能打」。墙后看不见的敌人照样会开枪，只是不在画面上先暴露自己。

---

## 1. 一盏灯，一份多边形

每帧开始，三个人各算一次：

1. **枪口**：`poseOf / muzzleOf` 给出世界坐标与枪管角（与子弹、加亮锥、命中判定共用同一份，见 `pose.js`）。
2. **射程**：提灯人 380 / `nighteyes` 368 / 举灯 346 / 其余 320，斜持时乘 `0.62 + 0.38 × poseT`。
3. **遮挡**：从枪口发一扇 96 条射线，每条与「墙矩形 + 此刻立着的门板」求最近交点（slab 法），得到可见多边形（`lighting.js`）。
4. **身边余光**：同一套墙再算一个半径 118 的 40 边圆，负责「站定的人不是瞎子」。

结果挂在 `game.lights` 上，画光、画暗、裁敌人、算掉落都用这一份。改一个数，三处一起变。

## 2. 暗部怎么盖

不是给世界调色，而是在世界之上盖一张**夜**（1280×800 离屏画布，`drawNight`）：

```
整张盖一层 rgba(3,5,9,α)
  → destination-out 挖掉：手电多边形（三层楔形 + 径向淡出）
  → destination-out 挖掉：身边余光（同样被墙切）
  → 整张 drawImage 到画面
```

因此「照到」是**原亮度**，「照不到」是**只剩 α 的黑**。光不会越过墙，因为多边形本来就被墙截断；光锥的加亮层（`drawFlashlights`）也裁在同一块多边形里。

α 取值：

| 案子 | 条件 | α | 说明 |
| --- | --- | --- | --- |
| 第一案 | 电闸还合着 | 0.12 | 礼堂灯亮，只压一点 |
| 第一案 | 拉下电闸 | 0.90 | 全场只剩手电 |
| 第二案 | 夜里 | 0.88 → 天亮 0.28 | 随 `clock` 在 2 秒内线性过渡 |
| 第三、四案 | — | 0.86 | 站台与稻田 |
| 第五案 | — | 0.90 | 十三楼最后一层最黑 |

## 3. 谁会被藏起来

- **敌人**：`sightAt()` 要求「在某人视距内」**且**「与那人之间没有墙/门板」（`wallClear`，每 5 px 采样，margin 2）。不满足就不画。——案一墙后的土蜘蛛不会再画出来。
- **掉落物**：同一条规则。
- **家具与墙**：永远画，只是被夜压暗；这样玩家仍有房间的轮廓感，不会在纯黑里迷路。
- **队友**：画在夜之上。他们是光源，也是玩家的棋子，任何时候都要读得清。
- **子弹/曳光**：画在夜之上（光）。
- **目标箭头**：画在夜之上（导航）。

家具**不挡光**：镜头是正上方，座位、箱子很矮，光从上面过。挡光的只有墙和门板。

## 4. 性能

- 遮挡矩形按 `level.sightGeometry().revision` 缓存，换楼/换门才重建。
- 每帧 3 × (96 + 40) 条射线，约 2 万次矩形求交；离屏遮罩 3 次全屏填充。
- 实测 `nw-perf` median 16.7 ms（与改动前一致），`nw-light` 五案各画一帧无 pageerror。

## 5. 验收

`tools/nw-light.mjs`：

- 案一：墙后一点 `seenAt = 0`，墙后敌人 `seen === false`；
- 朝东打，墙在 x=464，多边形最远点 `x ≤ 465`；
- 同一帧锥心亮度 ≥ 暗处 2.5 倍；拉电闸后整屏平均亮度 < 亮灯时的 65%；
- 五案各一帧：每案 3 个光锥多边形，被藏起来的敌人确实都在墙后。

## 6. 调参入口

| 想改 | 位置 |
| --- | --- |
| 锥形半角 / 射线数 | `buildLights()` 的 `half = 0.36`、`cone(..., 96)` |
| 射程 | `lightReach()` |
| 余光半径 | `circle(..., 118, ...)` 与 `drawNight` 里的 118 |
| 夜的浓度 | `nightAlpha()` |
| 敌人可见判定 | `sightAt()` 与 `level.wallClear()` |
| 光锥加亮的亮度 | `drawFlashlights()` 的 8 层 alpha |
